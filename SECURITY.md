# Security

Engineering Twin is designed around a local-first, read-only source model.

## Product security principles

- Source repositories remain read-only during analysis.
- Local UI binds to loopback only.
- Runtime is offline-first.
- Repository conclusions are tied to exact Git SHA evidence.
- Commercial product source code is maintained separately from this public repository.
- Secrets, signing keys, entitlement secrets and customer repository data are never stored in this public repository.

## Reporting

Do not post credentials, private repository contents or sensitive vulnerability details in public issues.

For sensitive reports, contact RockIn AI through the GitHub account and request a private reporting channel.
